= VM ライフサイクル管理
:navtitle:

== 概要

本モジュールでは、OpenShift Virtualization における仮想マシンのライフサイクル管理について学習します。イメージのインポート、ゴールデンイメージ、クローン、スナップショット、起動設定が含まれます。これらのワークフローを理解することで、再利用可能な VM イメージの作成、コピーの迅速なデプロイ、バックアップと復旧の管理が可能になります。

== 学習目標

* 既存の qcow2 ディスクイメージを OpenShift Virtualization にインポートする方法
* 一貫したデプロイのために再利用可能なゴールデンイメージを作成、管理する方法
* namespace 内および namespace 間で VM をクローンする方法
* VM スナップショットを作成、管理、復元する方法
* 起動順序、起動ソース、UEFI/Secure Boot モードを設定する方法

== 前提条件

VM ライフサイクル管理に取り組む前に、以下の環境が整っていることを確認してください。

* OpenShift 4.18 以降と OpenShift Virtualization Operator がインストールされていること
* ReadWriteMany アクセスモードをサポートする StorageClass が設定されていること
* CLI ツールがインストールされていること: `oc`, `virtctl`, `kubectl`
* PersistentVolumeClaims および DataVolumes に関する基本的な理解

xref:import-qcow2-boot-volume.adoc[]::
既存の KVM プラットフォームから qcow2 ディスクイメージをインポートし、OpenShift Virtualization でブートボリュームを作成して、スムーズな VM 移行を実現します。

xref:custom-golden-images.adoc[]::
事前にソフトウェアと設定が構成された再利用可能なゴールデンイメージを作成し、環境全体で一貫した VM デプロイを行います。

xref:golden-images-troubleshooting.adoc[]::

既存の VM をクローンして同一またはカスタマイズされたインスタンスを迅速にデプロイします。namespace をまたいだクローンや、cloud-init を使用したクローン後のカスタマイズも含まれます。

xref:vm-snapshots.adoc[]::
VM スナップショットを作成、管理、復元し、迅速なロールバック、安全な変更テスト、メンテナンス前のバックアップポイントとして活用します。

xref:boot-order-boot-sources.adoc[]::
