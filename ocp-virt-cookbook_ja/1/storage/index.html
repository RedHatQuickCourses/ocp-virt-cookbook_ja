ストレージ設定

概要

本モジュールでは、OpenShift Virtualization のストレージ設定について学習します。これには、LVM Storage Operator、HostPath Provisioner、ストレージの問題のトラブルシューティングが含まれます。

仮想マシン (VM) はディスクやデータ用に永続ストレージを必要とするため、適切なストレージ設定は VM のデプロイにおいて不可欠です。

学習目標

このセクションでは、以下の内容を学習します。

  • ローカルディスクストレージ向けの LVM Storage Operator のインストールおよび設定方法

  • シンプルなローカルストレージ向けの HostPath Provisioner の設定方法

  • 自動プロビジョニングのための default StorageClass の設定方法

  • 一般的なストレージの問題のトラブルシューティング方法

  • OpenShift Virtualization におけるストレージ設定のベストプラクティス

OpenShift Virtualization のストレージオプション

OpenShift Virtualization は、さまざまなストレージバックエンドをサポートしています。

  • LVM Storage: Logical Volume Manager を使用したローカルディスクストレージ (本モジュールで解説)

  • HostPath Provisioner: シンプルなローカルストレージのプロビジョニング (本モジュールで解説)

  • Ceph/ODF: 分散ブロックストレージおよびファイルストレージ

  • NFS: ネットワーク接続ストレージ

  • 外部ストレージプロバイダー: AWS EBS、Azure Disk など

本モジュールでは、Single Node OpenShift (SNO) やベアメタル環境に最適な、ローカルストレージのシナリオ向けの LVM Storage と HostPath Provisioner について解説します。

ライブマイグレーションでは、マイグレーション中に移行元ノードと移行先ノードの両方から VM ディスクにアクセスできる必要があります。ODF はこれを 2 つの方法でサポートしています。複数のノードからの同時アクセスを可能にする Block モードの Ceph RBD (I/O パフォーマンスが高いため、VM ワークロードに推奨される RWX マルチアタッチ) と、共有ファイルシステムアクセスを提供する Filesystem モードの CephFS (RWX) です。NFS も RWX アクセスを提供します。ライブマイグレーションを必要とする実稼働クラスターには、Ceph RBD を備えた ODF が推奨されるソリューションです。

前提条件

このセクションのチュートリアルを進める前に、以下が用意されていることを確認してください。

  • OpenShift 4.18 以降のクラスター

  • クラスター管理者権限

  • クラスターノード上の少なくとも 1 つの予備ローカルディスク

  • Linux のストレージ概念 (LVM、ブロックデバイス) に関する基本的な知識

各セクション

LVM Storage Operator のインストール

ローカルディスクを使用して LVM Storage Operator をインストールおよび設定するためのステップバイステップガイドです。

LVM Storage Operator のトラブルシューティング

LVM ストレージの問題を診断および解決するためのトラブルシューティングガイドです。

HostPath Provisioner を使用したローカルストレージ

開発、テスト、シングルノードクラスターのシナリオ向けに、HostPath Provisioner を使用したローカルストレージの設定ガイドです。

異なる Storage Class を使用したマルチディスク VM の構成

異なる StorageClass を使用して複数のディスクを持つ VM の設定ガイドです。

デフォルト Storage Class の重要性

デフォルト Storage Class の設定は、OpenShift Virtualization にとって非常に重要です。

  • ブートソースイメージ: DataSource OS イメージにはデフォルト Storage Class が必要です

  • 自動プロビジョニング: ストレージを明示的に指定しなくても VM を作成できます

  • テンプレートのサポート: VM テンプレートがすぐに使用できます

  • 運用管理の簡素化: クラスター全体で一貫したストレージプロビジョニングが可能になります

詳細については、LVM Operator ガイドの Step 5: Set Default StorageClass を参照してください。
