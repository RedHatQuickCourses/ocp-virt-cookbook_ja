スタートガイド

概要

このモジュールでは、OpenShift Virtualization を使い始めるために必要な基本ツールと基本的な設定について説明します。OpenShift Virtualization が初めての方でも、知識を再確認したい方でも、これらのガイドを活用して迅速に環境を構築できます。

対象読者

担当する役割によって、このモジュールで進むべきパスが異なります。

VMware または Hyper-V から移行する VM 管理者

まず 前提条件とセットアップ で環境を把握します。次に OpenShift Virtualization Operator のインストールと設定 と Web コンソールを使用したテンプレートからの VM の作成 に従って、Web コンソールから最初の VM を作成します。続いて VM ライフサイクルの状態と基本操作の理解 で OpenShift における VM の管理方法を学びます。

テスト VM を必要とする開発者

クイックスタート: 5 分で作成する最初の VM から開始して、数分で VM を稼働させます。その後、virtctl を使用した VM 管理 を読んでコマンドラインから VM を管理する方法を学びます。

プラットフォームエンジニア

完全な学習パスに従って、前提条件とセットアップ、OpenShift Virtualization Operator のインストールと設定、デフォルト Storage Class の設定、および両方の VM 作成チュートリアルを順番に進めます。このモジュールを完了した後は、Networking モジュールおよび Storage モジュールに進んでください。

評価担当者または意思決定者

OpenShift Virtualization Operator のインストールと設定 を読んで、Operator が提供する機能を理解します。次に Web コンソールを使用したテンプレートからの VM の作成 に従って、コンソールで VM が稼働している様子を確認します。VM ライフサイクルの状態と基本操作の理解 のページでは、日常的な管理操作について説明しています。

学習内容

このセクションでは、以下の内容を学習します。

  • OpenShift Virtualization を利用するための前提条件と必要なツール

  • 仮想マシンの管理に使用する virtctl コマンドラインツールの基本的な使い方

  • 仮想マシンデプロイメントのためのデフォルトストレージの設定方法

  • cloud-init の基礎と VM 初期化のパターン

前提条件

このセクションのチュートリアルを進める前に、以下の準備ができていることを確認してください。

  • OpenShift Virtualization Operator がインストールされた OpenShift 4.18+ クラスター

  • クラスター管理者アクセス権限、または適切な RBAC 権限

  • インストール済みの CLI ツール: oc、kubectl、virtctl

  • Kubernetes/OpenShift の概念に関する基本的な理解
