仮想マシンの設定

概要

本セクションでは、OpenShift Virtualization における仮想マシンの設定について説明します。これには、DNS 名前解決、リモートアクセス手法、ノードへの配置制御、ホットプラグ、VM テンプレートが含まれます。

学習目標

OpenShift Virtualization で仮想マシンを設定およびカスタマイズする方法を学びます。

  • VM 間および Pod 対 VM 通信のための内部 DNS 名前解決

  • Linux および Windows VM へのリモートアクセス手法

  • Selector、Affinity、Anti-affinity を使用したノード配置

  • 専用ノードへのインフラストラクチャコンポーネントの配置

  • 稼働中の VM に対するボリュームおよびネットワークインターフェースのホットプラグ

  • 繰り返しのデプロイのためのカスタム VM テンプレートの作成

前提条件

VM の設定作業を行う前に、以下の環境が整っていることを確認してください。

  • OpenShift 4.18 以降および OpenShift Virtualization Operator がインストール済みであること

  • 仮想マシンおよびネットワークに関する基本的な理解があること

  • YAML 構文に慣れていること

  • 次の CLI ツールがインストールされていること: oc, virtctl, kubectl

トピック

仮想マシンの内部 DNS 解決

クラスター内の Kubernetes サービスを使用した、VM 間および Pod 対 VM 通信のための内部 DNS 名前解決の設定

Linux 仮想マシンへのリモートアクセス

コンソール、VNC、virtctl 経由の SSH、NodePort サービス、ポートフォワーディング、および直接ネットワークアクセスなど、Linux 仮想マシンにアクセスするための複数の方法

Linux VM へのリモートアクセスに関するトラブルシューティング

診断コマンドや一般的な問題の解決策を含む、すべての VM リモートアクセス手法のトラブルシューティングガイド

Red Hat OpenShift 上の Windows 11 VM にリモートデスクトップでアクセスする方法

LoadBalancer または NodePort サービスを使用した、Windows 仮想マシンへの外部リモートデスクトッププロトコル (RDP) アクセスの設定

OpenShift Virtualization Infrastructure の配置戦略

専用のインフラストラクチャノードおよび高可用性を実現するために、HyperConverged カスタムリソースを使用して OpenShift Virtualization インフラストラクチャコンポーネント (virt-controller, virt-api, virt-handler, CDI) の配置の制御

Selector および Affinity rule による VM ノードの配置

パフォーマンス、可用性、ワークロード分離のために、NodeSelector、NodeAffinity、Pod Affinity/Anti-Affinity rule を使用して、クラスターノード間での VM の配置を制御

実行中の VM へのボリュームおよびネットワークインターフェースのホットプラグ

virtctl を使用して、ダウンタイムなしで稼働中の VM に対してストレージボリュームやネットワークインターフェースを動的に追加および削除

カスタム仮想マシンテンプレートの作成

OpenShift Virtualization コンソールおよびコマンドラインの両方から、迅速で繰り返し可能なデプロイを行うためのカスタム VM テンプレートを作成
